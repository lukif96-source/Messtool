Über SOLPRO

SOLPRO ist ein professionelles Planungssystem für PV-Anlagen mit Fokus auf Wechselrichter-Konfiguration und String-Planung. Das System unterstützt verschiedene Wechselrichter-Hersteller wie SMA, Huawei und Fronius und ermöglicht eine flexible, projektbasierte Arbeitsweise.

Features

  • Dynamische Wechselrichter-Konfiguration
  • MPPT-basierte String-Planung
  • Projekt-Management mit Templates
  • Plausibilitäts-Prüfungen
  • Cloud-Sync mit Supabase
  • Export in verschiedene Formate

Version

Version 1.0.0 · 2024

FAQ

Häufig gestellte Fragen

Wie erstelle ich ein neues Projekt?

Klicke auf den "+ Neues Projekt" Button in der Navigation oben rechts. Gib einen Projektnamen ein, wähle optional ein Template und klicke auf "Erstellen".

Wie funktionieren die MPPTs?

Gib einfach die Anzahl der MPPTs und die Eingänge pro MPPT ein. Die meisten Wechselrichter haben 2 Eingänge pro MPPT, manche Modelle auch 3. Das System erstellt automatisch die entsprechende Matrix.

Wie speichere ich meine Daten?

Daten werden automatisch im LocalStorage gespeichert. Für Cloud-Sync kannst du Supabase im Setup konfigurieren und dann auf "☁️ Speichern" klicken.

Welche Export-Formate sind verfügbar?

Excel-Exporte für GAK-Pickerl, String-Nummern und Prüfprotokolle, CSV-Export, PDF-Druckansicht und Validierungsberichte als Textdatei.

Was bedeuten die Validierungsregeln?

Das System prüft deine Eingaben auf Plausibilität: max. 30 Module pro String, Spannungsbereich 200-1000V, max. 15A Strom. Warnungen und Fehler werden im Validierungsbericht angezeigt.
